# Temporizador Regressivo

Temporizador regressivo feito com **HTML, CSS e JavaScript**. Permite que o usuário escolha uma data e horário futuros e exibe a contagem em **dias, horas, minutos e segundos**.

## Funcionalidades
- Contagem regressiva dinâmica.
- Validação de data futura.
- Exibição visual com caixas separadas.
- Alerta quando a contagem termina.

## Como Usar
1. Abra `index.html` no navegador.
2. Escolha uma data e horário futuros.
3. Clique em **Iniciar**.
